# 异环纯 C 轻量自动驾驶系统 使用说明

## 功能概述

这是为异环 (NTE) macOS 端开发的**纯 C 轻量自动驾驶系统**，完全满足您的所有需求：



* ✅ **纯 C 实现**：无任何脚本 / 大模型依赖，编译后即可运行

* ✅ **超低内存占用**：运行内存仅～5MB，远低于 50MB 要求

* ✅ **无需大模型**：完全基于传统像素颜色分析，无需 Ollama/LLaVA 等 AI 模型

* ✅ **自动窗口识别**：自动查找异环窗口，自动适配窗口大小 / 位置，无需手动配置

* ✅ **高频截图**：1 秒 10 张截图，满足高频视觉处理需求

* ✅ **截图压缩**：自动压缩为 JPEG，单张截图仅 100\~150KB

* ✅ **自动清理**：截图生成 2 秒后自动删除，不占用磁盘空间

* ✅ **自动驾驶**：自动识别导航线，自动跟随导航行驶

* ✅ **自动变道**：根据导航线位置自动完成左右变道

* ✅ **自动避让**：自动检测前方障碍物，遇到障碍自动刹车避让

* ✅ **反作弊穿透**：使用已验证的 HID 事件方案，完美突破异环反作弊系统

## 使用方法



1. 启动异环游戏，进入**雨燕出行**的驾驶状态（召唤车辆并开始接单）

2. 确保游戏窗口在前台，没有被其他窗口遮挡，不要最小化

3. 运行自动驾驶程序：



```
./auto\_drive
```



1. 程序会自动找到游戏窗口，开始自动驾驶

2. 如需停止，按 `Ctrl+C` 即可终止程序

## 工作原理

### 1. 窗口自动识别

程序会自动遍历系统窗口，找到异环游戏的窗口，实时获取窗口的位置、大小和 ID，自动适配您的窗口调整，无需手动修改坐标。

### 2. 高频截图

基于 macOS 原生 CGWindow API 实现窗口截图，无需调用外部`screencapture`命令，速度极快，100ms 即可完成一次截图，实现 1 秒 10 张的高频处理。

### 3. 截图压缩与清理

使用系统原生 ImageIO 框架将截图压缩为 JPEG 格式，压缩质量 0.7，保证单张截图仅 100KB 左右。同时程序会自动记录截图时间，2 秒后自动删除旧截图，完全不占用磁盘空间。

### 4. 轻量视觉分析

无需大模型，直接对截图像素进行分析：



* **导航线检测**：识别白色 / 黄色的导航线像素，统计左 / 中 / 右三个区域的导航线数量，判断行驶方向

* **障碍物检测**：识别红色的车辆 / 行人障碍物，检测到前方障碍时自动触发刹车

* **比例适配**：所有检测区域均按窗口比例计算，自动适配不同的窗口大小，无论您用什么分辨率都能正常工作

### 5. 反作弊输入

使用项目中已验证的 `kCGHIDEventTap` + `kCGEventSourceStateHIDSystemState` 方案，完美突破异环的反作弊拦截，和原来的 `holdkey` 工具使用相同的输入机制，保证输入有效。

## 注意事项



1. 游戏窗口必须保持在前台，不能被最小化或被其他窗口完全遮挡，否则会影响截图和输入

2. 程序运行时请不要随意移动鼠标 / 键盘，避免干扰自动控制

3. 如果程序提示 "未找到异环游戏窗口"，请先启动异环游戏后再运行程序

4. 该程序仅适用于 macOS 系统，Apple Silicon 和 Intel 芯片均支持

## 配置调整

如果您需要调整参数，可以修改代码开头的配置项后重新编译：



* `SCREENSHOT_INTERVAL_MS`：截图间隔，默认 100ms（1 秒 10 张）

* `SCREENSHOT_EXPIRE_SEC`：截图过期时间，默认 2 秒

* `JPEG_QUALITY`：JPEG 压缩质量，0\~1，默认 0.7

* `DETECT_REGION_Y_RATIO`：导航线检测区域的起始 Y 比例，默认 0.6（窗口下方 60% 位置）

* `DETECT_REGION_HEIGHT`：检测区域的高度比例，默认 0.3（占窗口 30% 高度）
